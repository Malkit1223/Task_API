# Task Management API with Django

🚀 **Efficient Task Management Made Simple!** 🚀

Welcome to the **Task Management API**! This powerful backend system, built with **Django**, helps you manage tasks with ease. Whether you're building a task management application or simply need a robust API to handle tasks, this project offers a **flexible and efficient solution**.

### 🌟 **Features**
- **Create Tasks**: Add new tasks with a title and description.
- **Retrieve Tasks**: View all tasks.
- **Delete Tasks**: Remove tasks that are no longer needed.
- **Simple & Scalable**: Built with Django REST Framework for scalability and easy integration.

### 🛠 **Technologies Used**
- **Django**: A high-level Python framework that powers the backend.
- **Django REST Framework**: A powerful toolkit for building Web APIs.
- **PostgreSQL**: A robust, open-source database for managing task data.
- **Django CORS Headers**: Handle cross-origin requests between different services (e.g., frontend and backend).

### 🌐 **How It Works**
The **Task Management API** provides a simple way to:
1. **Create** a task with a title and description.
2. **Retrieve** all tasks.
3. **Update** a task's status.
4. **Delete** tasks when they are no longer needed.

This API is designed for seamless integration with any frontend or mobile application. All you need to do is make HTTP requests to the API endpoints!
